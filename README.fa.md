# پورتفولیوی آمار مهندسی

این مخزن شامل دو پروژهٔ انگلیسی و قابل بازتولید از درس آمار مهندسی است: [استنتاج آماری کاربردی](phase1/README.md) و [نظریهٔ تخمین و رگرسیون](phase2/README.md).

هر فاز کد پایتون، نوت‌بوک اجراشده، آزمون‌ها، نمودارها و گزارش PDF مستقل دارد. از صفحهٔ [README اصلی](README.md) می‌توان گزارش‌ها، خروجی‌ها، روش بازتولید و محدودیت‌های تحلیل را دید.

داده‌ها نمونه یا دادهٔ آموزشی هستند و نتایج برای ادعای علی یا نتیجه‌گیری دربارهٔ جمعیت واقعی ارائه نشده‌اند. فایل‌های قدیمی، اسناد تمرین و خروجی‌های موقت در مخزن منتشر نشده‌اند.
